# Deliver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** POST approved canonical remittance payloads to the backend REST API with an idempotency key and a retry/backoff ladder, mark each `delivery` row `delivered` or `failed`, surface failures in the review UI with a Resend action, and drive it from `worker.run_deliveries()`.

**Architecture:** `ar_pipeline/deliver/` — `backend_client.py` (a thin `BackendClient` over an injectable `httpx.Client`, classifying each POST as ok / permanent-fail / transient-fail) and `deliverer.py` (`run_deliveries(session, backend_client, ...)` walks due `delivery` rows, one `begin_nested()` savepoint + commit per row, applying the backoff ladder). `worker.run_deliveries()` builds the real client and calls it. The review UI's Errors page gains a failed-deliveries table + a `POST /review/deliveries/{id}/resend` route. The stub backend is unchanged; failure paths are unit-tested with `httpx.MockTransport`, and one integration test runs the whole pipeline into the stub via `httpx.ASGITransport`.

**Tech Stack:** Python 3.12, `httpx` (sync `Client`, `MockTransport`, `ASGITransport`), SQLAlchemy 2.0 sync, FastAPI + Jinja2 (review UI), pytest + embedded `pgserver`.

**Spec:** `docs/superpowers/specs/2026-09-09-ar-email-extraction-design.md` — see the `### deliver/` module section, the "Amendments during implementation (Deliver plan, 2026-09-10)" block, the Data model `delivery` table, and the Error handling rows for delivery.

## Global Constraints

- Python `>=3.12`; packaging via `uv` (`uv run <cmd>`). No new dependencies — `httpx` is already a dep.
- SQLAlchemy 2.0 **sync only**. `deliverer.run_deliveries` follows `advance_once`'s transaction discipline: a per-row `session.begin_nested()` savepoint, `session.commit()` after each row (success or failure), so one slow backend call never holds a transaction open across the batch. `review/service.py` functions still take `session` first and never commit.
- The `delivery` table already has every column needed (`id`, `extraction_id`, `status`, `attempts`, `next_attempt_at`, `last_error`, `last_attempt_at`, `delivered_at`). `DELIVERY_STATUSES = ("pending", "delivered", "failed")`. **No migration in this plan.**
- Idempotency key = the `extraction` id (a UUID string), sent as HTTP header `Idempotency-Key`.
- `Settings.backend_url` (str, default `""`) is the base URL; the client POSTs to `backend_url.rstrip("/") + "/remittances"`. `Settings.backend_auth_header` (`SecretStr`, default `""`) holds the **complete** `Authorization` header value (e.g. `"Bearer xyz"`); send an `Authorization` header only when it is non-empty.
- Backoff ladder `_BACKOFF = [timedelta(minutes=1), timedelta(minutes=5), timedelta(minutes=30), timedelta(hours=2), timedelta(hours=6)]` — 6 attempts total, then `failed`.
- Outcome classification: HTTP `2xx` → ok; `4xx` except `429` → permanent fail; `429` / `5xx` / `httpx.TimeoutException` / `httpx.TransportError` → transient fail.
- All timestamps timezone-aware UTC (`datetime.now(tz=UTC)`). `run_deliveries` takes an injected `now` for deterministic tests.
- Gate after every task: `uv run ruff check`, `uv run ruff format --check`, `uv run mypy`, `uv run pytest -q` — all clean. Baseline before this plan: **221 passed, 2 deselected**.

```python
"""POST a canonical remittance payload to the backend REST API.

``BackendClient`` wraps an injectable ``httpx.Client`` (tests pass an
``httpx.MockTransport`` / ``ASGITransport``) and classifies each POST as
``ok`` / ``permanent_fail`` / ``transient_fail`` so ``deliverer`` can decide
between marking the row delivered, failing it, or scheduling a retry.
"""

from __future__ import annotations

from dataclasses import dataclass
from typing import Literal

import httpx

from ar_pipeline.config import get_settings

DeliveryOutcome = Literal["ok", "permanent_fail", "transient_fail"]

_DETAIL_CAP = 500
_TIMEOUT = httpx.Timeout(30.0)


@dataclass(frozen=True)
class DeliveryResult:
    outcome: DeliveryOutcome
    status_code: int | None
    detail: str


def _bounded(s: str) -> str:
    return s if len(s) <= _DETAIL_CAP else s[: _DETAIL_CAP - 1] + "…"


class BackendClient:
    def __init__(
        self,
        *,
        base_url: str,
        auth_header: str = "",
        http: httpx.Client | None = None,
    ) -> None:
        self._base = base_url.rstrip("/")
        self._auth_header = auth_header
        self._http = http or httpx.Client(base_url=self._base, timeout=_TIMEOUT)

    def send(self, payload: dict, idempotency_key: str) -> DeliveryResult:
        headers = {"Idempotency-Key": idempotency_key}
        if self._auth_header:
            headers["Authorization"] = self._auth_header
        try:
            resp = self._http.post("/remittances", json=payload, headers=headers)
        except (httpx.TimeoutException, httpx.TransportError) as exc:
            return DeliveryResult("transient_fail", None, _bounded(repr(exc)))

        code = resp.status_code
        if 200 <= code < 300:
            return DeliveryResult("ok", code, _bounded(resp.text))
        if code == 429 or code >= 500:
            return DeliveryResult("transient_fail", code, _bounded(resp.text))
        return DeliveryResult("permanent_fail", code, _bounded(f"{code} {resp.text}"))


def get_backend_client() -> BackendClient:
    s = get_settings()
    return BackendClient(
        base_url=s.backend_url,
        auth_header=s.backend_auth_header.get_secret_value(),
    )
```

Note: `httpx.TimeoutException` is NOT a subclass of `httpx.TransportError`, hence the tuple. `repr(httpx.TimeoutException(...))` contains `"TimeoutException"` — the test accepts either that or the message.

```python
from collections.abc import Iterator

from ar_pipeline.deliver.backend_client import DeliveryResult


class FakeBackendClient:
    """Returns queued DeliveryResults (or repeats the last one). Records calls."""

    def __init__(self, results: list[DeliveryResult] | None = None) -> None:
        self._results = list(results or [DeliveryResult("ok", 201, "")])
        self._it: Iterator[DeliveryResult] = iter(self._results)
        self._last = self._results[-1]
        self.calls: list[tuple[dict, str]] = []

    def send(self, payload: dict, idempotency_key: str) -> DeliveryResult:
        self.calls.append((payload, idempotency_key))
        try:
            self._last = next(self._it)
        except StopIteration:
            pass
        return self._last
```

```python
"""Walk due ``delivery`` rows and POST them to the backend.

Same transaction discipline as ``pipeline/advance.py``: one
``begin_nested()`` savepoint + ``commit()`` per row, so a slow backend call
never pins one transaction across the batch, and a poison row fails only
itself.
"""

from __future__ import annotations

from dataclasses import dataclass
from datetime import UTC, datetime, timedelta
from typing import Protocol

from sqlalchemy import select
from sqlalchemy.orm import Session

from ar_pipeline.deliver.backend_client import DeliveryResult
from ar_pipeline.db.models import Delivery, Extraction

_BACKOFF: list[timedelta] = [
    timedelta(minutes=1),
    timedelta(minutes=5),
    timedelta(minutes=30),
    timedelta(hours=2),
    timedelta(hours=6),
]

_ERR_CAP = 1000


class SendClient(Protocol):
    def send(self, payload: dict, idempotency_key: str) -> DeliveryResult: ...


@dataclass(frozen=True)
class DeliveryStats:
    delivered: int = 0
    failed: int = 0
    retrying: int = 0


def _cap(s: str) -> str:
    return s if len(s) <= _ERR_CAP else s[: _ERR_CAP - 1] + "…"


def run_deliveries(
    session: Session,
    backend_client: SendClient,
    *,
    batch: int = 20,
    now: datetime | None = None,
) -> DeliveryStats:
    now = now or datetime.now(tz=UTC)
    rows = list(
        session.scalars(
            select(Delivery)
            .where(
                Delivery.status == "pending",
                (Delivery.next_attempt_at.is_(None)) | (Delivery.next_attempt_at <= now),
            )
            .order_by(Delivery.next_attempt_at.asc().nulls_first(), Delivery.id)
            .limit(batch)
        )
    )

    delivered = failed = retrying = 0
    for row in rows:
        try:
            with session.begin_nested():
                outcome = _deliver_one(session, row, backend_client, now)
        except Exception as exc:  # savepoint rolled back
            row.status = "failed"
            row.last_error = _cap(f"{type(exc).__name__}: {exc}")
            outcome = "failed"

        if outcome == "delivered":
            delivered += 1
        elif outcome == "failed":
            failed += 1
        else:
            retrying += 1
        session.commit()

    return DeliveryStats(delivered=delivered, failed=failed, retrying=retrying)


def _deliver_one(
    session: Session, row: Delivery, backend_client: SendClient, now: datetime
) -> str:
    row.attempts += 1
    row.last_attempt_at = now

    ext = session.get(Extraction, row.extraction_id)
    if ext is None or ext.status != "approved":
        row.status = "failed"
        row.last_error = "extraction no longer approved"
        return "failed"

    result = backend_client.send(dict(ext.canonical), str(ext.id))

    if result.outcome == "ok":
        row.status = "delivered"
        row.delivered_at = now
        row.last_error = None
        return "delivered"

    row.last_error = _cap(f"{result.status_code}: {result.detail}")
    if result.outcome == "permanent_fail":
        row.status = "failed"
        return "failed"

    # transient_fail
    if row.attempts > len(_BACKOFF):
        row.status = "failed"
        return "failed"
    row.next_attempt_at = now + _BACKOFF[row.attempts - 1]
    return "retrying"
```

```python
@dataclass(frozen=True)
class FailedDeliveryRow:
    delivery_id: uuid.UUID
    extraction_id: uuid.UUID
    email_subject: str
    sender_address: str
    attempts: int
    last_attempt_at: datetime | None
    last_error: str | None


def list_failed_deliveries(session: Session) -> list[FailedDeliveryRow]:
    rows = session.execute(
        select(Delivery, Email)
        .join(Extraction, Delivery.extraction_id == Extraction.id)
        .join(Email, Extraction.email_id == Email.id)
        .where(Delivery.status == "failed")
        .order_by(Delivery.last_attempt_at.desc().nulls_last())
    ).all()
    return [
        FailedDeliveryRow(
            delivery_id=d.id,
            extraction_id=d.extraction_id,
            email_subject=e.subject,
            sender_address=e.sender_address,
            attempts=d.attempts,
            last_attempt_at=d.last_attempt_at,
            last_error=d.last_error,
        )
        for d, e in rows
    ]


def resend_delivery(session: Session, delivery_id: uuid.UUID) -> None:
    d = session.get(Delivery, delivery_id)
    if d is None:
        raise ReviewError("delivery not found")
    if d.status != "failed":
        raise ReviewError(f"delivery is {d.status}, not failed")
    d.status = "pending"
    d.attempts = 0
    d.next_attempt_at = func.now()
    d.last_error = None
    d.delivered_at = None
    session.flush()
```
